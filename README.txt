WORLD DOMINION — Prototype 0.1

Contenu
- index.html : première version jouable.

Lancer sur ordinateur
1. Décompresse le ZIP.
2. Ouvre index.html avec Chrome, Edge, Firefox ou Safari.
3. Une connexion Internet est nécessaire pour charger Leaflet et les données de carte.

Lancer sur iPhone
Le plus simple est de publier le dossier sur GitHub Pages depuis un ordinateur, puis d'ouvrir le lien dans Safari. Le fichier seul peut aussi être ouvert avec une application de fichiers/code qui prend en charge les pages HTML, mais le chargement des ressources externes dépend du navigateur.

État actuel
- Carte politique mondiale chargée depuis un jeu de données GeoJSON externe.
- Sélection des pays.
- Panneau d'information.
- Changement visuel de propriétaire pour tester la mécanique.
- Réinitialisation.

Limites assumées
- Les provinces, les vraies données économiques, la diplomatie, l'IA et les sauvegardes ne sont pas encore développées.
- Le changement de propriétaire est une démonstration locale, pas une simulation géopolitique complète.
